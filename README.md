# GeminiBots — живые боты для Garry's Mod

Аддон заменяет статичное поведение стандартных ботов (`bot`) полноценным ИИ: боты ходят по карте, слышат, воюют, подбирают оружие, пишут в чат и играют по правилам режимов. Версия 1.0.0.

## Возможности

- **Движение**: навмеш, прыжки, присед под низкие проемы, разбивание стекла, открытие дверей, баннихоп.
- **Бой**: доводка прицела, упреждение, разброс, стрейфы, выбор пушки под дистанцию, гранаты навесом, прострел стекла.
- **Чувства**: конус зрения, слух шагов и выстрелов, память о цели за укрытием.
- **Чат**: фразы после фрагов/смертей, умный контекст (K/D, стрики, пинг), приветы и дуэли с игроками.
- **Оружие**: Арсенал со сканом паков (HL2, M9K, TFA, ArcCW, CW2.0, SWCS, FA:S), подбор стволов с карты.
- **Режимы**: SWCS (тактика, флешки, молики, C4), Murder, HL2-детматч, NPC и PvE.
- **Меню**: отдельное окно с темной/светлой темой, RU/EN (авто из языка игры), ESP с боксами и скелетами.
- **Свои FSM-состояния**: файлы в `data/` без правки аддона.

Подробности — в `docs/` (таблица внизу).

## Требования

- Garry's Mod, карта **с навмешем** (без него боты стоят).
- Опционально: ULX (команды `!bringbots`), SWCS, VJ Base / DrGBase, оружейные паки.

## Установка

1. Папку `geminibots` — в `GarrysMod/garrysmod/addons/` (для разработки удобнее `tools/deploy_to_gmod.bat` — зеркалит проект через `robocopy /MIR`).
2. Запусти карту. Нет навмеша — админу через 10 сек предложат сгенерировать (`nav_generate` вручную тоже работает, сервер подвиснет на минуты).
3. В консоль (`~`):
   ```console
   geminibots_add
   ```

## Быстрый старт

| Команда | Что делает |
|---|---|
| `geminibots_add` | Добавить бота |
| `geminibots_menu` | Открыть окно настроек (`bind p geminibots_menu`) |
| `geminibots_weapons_menu` | Открыть Арсенал |
| `geminibots_esp` | Вкл/выкл ESP (админам) |
| `geminibots_spawn_max` | Забить сервер ботами |
| `geminibots_kick_all` | Убрать всех ботов |

Настройки из меню и консоли сохраняются в `data/geminibots/convars.json` и переживают рестарт. Нужен рестарт карты: серверный и клиентский Lua применяется только после смены карты.
