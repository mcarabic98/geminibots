# Совместимость: SWCS, C4, Murder, HL2DM, NPC-базы

Файлы `lua/geminibots/server/compat/sv_*.lua` тихо спят, пока нет их режима/сущностей. В режимах применяется особый конфиг со снапшотом (`data/geminibots/*_prev_config.json`): при входе настройки сохраняются и подменяются, при выходе — возвращаются. Правки прямо в режиме при выходе затираются — так задумано.

## SWCS (`sv_swcs.lua`)

- Тактика: флеш/смок/декой на средней (300–1100) навесом — флеш и декой к врагу, дым завесой. Кулдаун 35–50 сек, после броска переоценка пушки.
- Декой: чужой звук в радиусе слуха — проверка через investigate (шанс `geminibots_swcs_decoy_chance`, 0.40; не повелся — этот декои не дергает).
- Флешка: на время `BlindUntilTime` бот слепоглухонемой (стоит/приседает, не ищет, не стреляет). Тумблера нет.
- Молик: огонь ближе `geminibots_swcs_fire_radius` (320) — отход вбок, стрельба продолжается. Выкл — `geminibots_swcs_fire_avoid 0`.

## C4 (`sv_c4.lua`, нужен SWCS, `geminibots_c4_enabled`)

Не работает в Murder и HL2-детматче (там минированию не место).

Директор назначает подрывника (минимум двое живых): ставит без свидетелей (5 сек никого живого ближе 1500, держит атаку 3 сек, где угодно) и убегает (500 урона / 1750 радиус, таймер `mp_c4timer` ~40 сек). Остальные: далеко — ищут, близко (100) — держат E (10 сек, 5 с набором; урон не прерывает, на врагов не отвлекаются). Времени не хватит — убегают. ESP: `БОМБА: ...`, бокс подрывника оранжевый, сапера циан.

## Murder (`sv_murder.lua`, оригинал)

Лодаут выкл (руки/нож/магнум режима). Вместо командного фильтра — фильтр ролей: убийца валит всех, мирняк — только известного убийцу (видел сам / пырнули / раскрыт туманом). Безоружный при известном убийце рядом — бежит. Чат фрагов/смертей/камбэков и дуэли выкл (приветы и `gg` работают). Зашедший посреди раунда играет сразу. Конфиг: лодаут выкл, шансы фрагов/смертей/камбэков 0, макс. дистанция 600.

## HL2-детматч (`sv_hl2mp.lua`, ремейк HL2DM)

FFA — бьют всех живых бойцов, TDM (`sv_hl2mp_teamplay 1`, читается вживую) — только чужую команду. Боты выводятся из спектаторов в меньшую команду и спавнятся (дозор каждые 5 сек). Конфиг: лодаут выкл (стволы режима + подбор), зрение 4000, слух выстрелов 6000, переохота раз в 8 сек. В ESP — строка `REBEL` / `COMBINE`.

## NPC-базы (`sv_npc_adapters.lua`, `perception/npcs/`)

Реестр как у оружейных адаптеров: префиксы классов, проверка «враг ли», поправка точки прицеливания. Из коробки: VJ Base (`npc_vj_*`: союзники и мирные по диспозиции не трогаем) и DrGBase (NextBot'ы: дружелюбные пропускаем, все вызовы чужого API в pcall). Без базы — generic: живой NPC/NextBot = враг. Список кэшируется раз в секунду.
