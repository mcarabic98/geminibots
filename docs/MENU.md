# Окно настроек и ESP

Отдельное окно (`geminibots_menu`, тоггл; удобно `bind p geminibots_menu`). С открытым окном можно ходить — клавиатура остается в игре. Вкладки: Основные, Оружие, Бой и движение, Админ, Меню. В Q-меню (Options и Utilities → GeminiBots) осталась только кнопка «Открыть меню» (+ Арсенал).

## Вкладка «Меню»

- Тема: темная / светлая.
- Акцент: 9 пресетов Catppuccin Mocha + свой цвет (миксер).
- Скругление 0–16, масштаб 85–115%, блюр 0–3, звуки кликов, анимации.
- Шрифт, частицы (выкл / созвездие / снег / дождь / искры) + тумблер «в цвете акцента».
- Язык: авто (берется из языка игры) → RU → EN, кнопка в шапке. Позиция окон запоминается.

Иконки вкладок и лого в шапке — векторные, рисуются кодом.

## ESP (`geminibots_esp`, только админам)

Боксы, полоса HP, инфо (ник, состояние, HP, цель, оружие), статусы (оглушение с секундами, огонь, бомба, звук проверки, путь). Опционально скелеты. Элементы отключаются отдельно:

`geminibots_esp_boxes`, `_hp`, `_info`, `_status`.

Особые строки: `ЧИТЕР: тир`, `БОМБА: ...`, в HL2-детматче — `REBEL` / `COMBINE`.
