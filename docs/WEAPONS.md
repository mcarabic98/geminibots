# Оружие: Арсенал, пул, адаптеры, подбор

## Арсенал (`geminibots_weapons_menu`)

Основной способ управлять пулом: скан всех SWEP сервера, поиск, фильтры по пакам и типам, пресеты типов (HL2 / M9K / пистолеты / винтовки / дробь / снайп. / ВСЁ / OFF), массовые вкл/выкл, «показать отсутствующие». Записей нет на сервере — скрыты (в `weapons.txt` остаются).

Технические базы паков (`*_base`, тулы, камеры, кулаки) в скан не попадают и из пула вычищаются (`geminibots_weapon_prune`). Упавший при выдаче ствол помечается сломанным (`[ОШИБКА]`, повторная попытка — `geminibots_weapon_clear_broken`).

## `weapons.txt`

`data/geminibots/weapons.txt` — класс на строку, `#` — коммент. Точная доводка типов по дампу: `geminibots_weapon_dump <префикс>` → `data/geminibots/weapon_dump.txt`.

## Адаптеры паков

Пак описывается файлом `lua/geminibots/server/combat/packs/wp_*.lua`: префиксы классов, kind (`frag` / `launcher` / `trap` / `melee` / `short` / `tactical`), паузы, подпись. Без адаптера пак работает на generic-скоринге (средние оценки). Вкл/выкл тактики пака — `geminibots_pack_list`, состояние в `data/geminibots/pack_adapters.json`. Несовместимые базы (`IncompatibleBases`, дефолт `weapon_swcs_base`) ботам не выдаются.

Покрыто: HL2, M9K, TFA, CW 2.0, ArcCW, FA:S, SWCS (навесные гранаты, тазер вплотную, тяжелый удар ножей, тактические броски — см. COMPAT.md).

## Подбор с карты

Бот идет к лежащему стволу тиром выше своего и берет касанием. Безоружный ищет далеко (4500), вооруженный — апгрейд рядом (1500). Свой такой же класс и ловушки (SLAM) игнорит. Расходники: тяжелое ранение (<40% HP) — к аптечке первым делом, потом батарея (<50% брони) и патроны под свои стволы (запас < двух магазинов). Взятие видно по исчезновению сущности. В Murder подбора нет — экипировкой владеет режим.

## Выбор в бою

Рулетка по весам под дистанцию (снайперка вдаль, автомат/ПП на средней, дробовик вплотную), переоценка раз в 1.5–3 сек, бонус текущей пушке против дерганья. Утилиты (физган, тулганы, камеры) не выбираются. В бою держится полоса идеальной дистанции ствола (снайпер ~1000, винтовки ~600, ПП ~450, пистолеты ~350, дробь ~200, рукопашка ~90). Гранатометы — с безопасной дистанции (РПГ от 550), при стене перед носом и в упор огонь запрещен. Гранаты — навесом по баллистике, если точка падения рядом с целью. Прострел: свежий след за стеклом/хрупким — очередь 0.7 сек в предсказанную точку (проверка преграды раз в 0.5 сек). Огонь — только по наводке в цель (ошибка взгляда ≤ 7°, +3 сек дожатия после срыва). Бетон/металл не пробиваем.
