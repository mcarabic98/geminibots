# История изменений

Сюда переехало все «раньше было так» из README — новым читателям это не нужно в основном тексте.

## Меню и Q-меню

- Было 4 вкладки настроек прямо в Q-меню. Стало: в Q одна кнопка «Открыть меню», все настройки — в отдельном окне (`geminibots_menu`).
- Построитель Q-меню сохранен как мост: отдельное окно собирается той же функцией.
- Кнопка языка была RU/EN. Стала: авто (из языка игры) → RU → EN.
- Пресеты оформления Discord/Minimal/Candy заменены на 9 акцентов Catppuccin Mocha + свой миксер.
- Silkicons вкладок заменены своими векторными иконками (красятся в тему). Лого в шапке: было 3 варианта на выбор, остался один (голова-бот с G).
- Режимы частиц были выкл/созвездие/снег/дождь. Добавлены искры + тумблер цвета акцента.
- Поля ввода и боксы значений открывают мини-диалог (печать в полях напрямую не работала — фокус клавиатуры у игры).
- Дебаг-команды `typing_debug`, `avatar_test`, `navwarn_test` удалены.

## Чат

- Старые `default_ru`/`toxic_ru`/`default_en` убраны из кода: их файлы надо удалить вручную один раз.
- Старый формат `[KILLS]`/`[DEATHS]` = `DEFAULT`, работает.
- Нулевые шансы не глушили насмешки (свой ролл) — теперь это задокументировано, а не баг.

## Оружие

- Списки и пресеты пула переехали из Q-меню в Арсенал.
- Тег клапбэка унифицирован: `{kfrags}`/`{fdeaths}` (вариант `{kdeaths}` неверный).
- Снапшот конфига в режимах (Murder, HL2DM) раньше проигрывал гонку рестору `convars.json` (очередь `RunConsoleCommand`); теперь применение отложено, поведение критично закрыто явными гейтами, режимные значения не сохраняются.

## Поведение

- Наблюдатели больше не считаются врагами (боты пятились от слежки в упор).
- Огонь — только по наводке в цель (+3 сек дожатия), раньше палили в стену при развороте.
- Подбор пушек с карты добавлен (модуль Scavenger); в Murder лута нет.
- NPC-базы: раньше только `npc_*`, теперь адаптеры VJ/DrGBase (+NextBot'ы вообще).
- HL2-детматч: вывод ботов из спектаторов, развод охоты по карте, строка команды в ESP.
- Поддержка выживания с некстботами удалена целиком (никто не играет): compat, состояние `evade`, строка угрозы в ESP.
- Подъем мертвых в песочнице: трупы поднимаются сами раз в 3 сек (режимы со своим респауном не трогаем).
- Аудит боя/чувств: ролл прицела раз на цель, одинарное сглаживание взгляда, один LOS в скане, липкая цель, утилиты вне боя, перезарядка без атаки, присед удержанием, троттлы путей/переоценок/дуг, взгляд-осмотр жив, слепой стоит.
